# Project Statement

## 1. Problem Statement

Manual attendance recording is a time-consuming process and can require repetitive work from teachers or instructors. It can also lead to mistakes while recording or maintaining attendance records.

The objective of this project is to develop a face recognition based attendance management system that can identify registered students through a webcam and record their attendance automatically.

---

## 2. Scope of the Project

The project focuses on developing a local computer-based attendance system using Python and OpenCV.

The system covers:

- Student registration
- Face image capture
- Face recognition model training
- Automatic attendance using face recognition
- Subject-wise attendance recording
- CSV-based attendance storage
- Attendance record viewing

The current project is intended for small-scale educational environments such as classrooms, laboratories, and training institutes.

---

## 3. Target Users

The primary target users of the system are:

- Teachers
- Faculty members
- College instructors
- Training institute instructors
- Students for attendance record verification

---

## 4. High-Level Features

The major features of the project include:

### Student Registration
Allows the user to enter student enrollment details and register face images.

### Face Image Capture
Uses a webcam to detect and capture multiple images of a student's face.

### Face Recognition Model Training
Processes the captured images and creates a trained face recognition model.

### Automatic Attendance
Recognizes registered students through the webcam and records their attendance.

### Subject-wise Attendance
Allows attendance to be recorded for a particular subject.

### Attendance Storage
Stores attendance records in CSV files.

### Attendance Viewing
Displays stored attendance records in a tabular format.

### Voice Feedback
Provides text-to-speech feedback for important system operations.
